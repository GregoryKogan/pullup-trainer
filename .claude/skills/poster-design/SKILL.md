# Poster / Swiss

## Где источник правды

| Что | Путь |
|---|---|
| Спека (читать целиком при новом экране) | `spec/design/poster-design.md` |
| Токены (генерируются) | `spec/design/theme-tokens.css` |
| Палитры (исходник) | `spec/design/build-assets.py` |
| Мокапы-референс | `spec/design/mockups/index.html` |
| Слаги палитр в коде | `src/utils/theme.ts` |

**Токены и мокапы генерируются.** Правишь палитру в `build-assets.py`, затем
`python3 spec/design/build-assets.py` — он регенерирует `theme-tokens.css`, мокапы и README.
Ручная правка `theme-tokens.css` будет затёрта.

## Характер

Постерная типографика в швейцарской традиции: плоские заливки, рамки 2px, радиус 2px везде,
офсетные тени 4–5px сплошным цветом, гигантские контурные цифры, капс-заголовки, цветные
плашки-лейблы.

**Запрещено:** градиенты, блюр, свечения, скругления больше 2px, эмодзи, растровые иконки,
CSS-фреймворки, компонентные библиотеки.

Иконки — только inline SVG (`src/components/icons/`). Точечные headless-инструменты
(выбор дат и т.п.) допустимы, только если реально нужны и темизируются токенами.

## Токены

Все цвета **только** из переменных. Хардкод цвета в SFC — дефект ревью.

```
--bg  --bg2  --card  --ink  --muted  --line
--accent  --accent-ink  --accent2
--ok  --warn  --bad  --shadow
```

`--accent-ink` — цвет текста поверх `--accent` (не `--ink`!). Семантические `--ok/--warn/--bad`
подобраны так, чтобы не сливаться с акцентом палитры — не подменяй их акцентом.

## Темы

14 палитр × 2 режима. Механика: `data-theme="<slug>-<mode>"` на `<html>`; режим `system`
резолвится через `prefers-color-scheme`. Дефолт — P01 Volt + system.

Слаги: `p01-volt`, `p02-signal-orange`, `p03-cobalt`, `p04-magenta-pop`, `p05-taxi`,
`p06-paper-red`, `p07-mint-terminal`, `p08-amber`, `p09-cyan-future`, `p10-crimson`,
`p11-spring-green`, `p12-ultraviolet`, `p13-coral-sunrise`, `p14-mono-ink`.

Добавляешь палитру — трогаешь три места: `build-assets.py` (значения), `src/utils/theme.ts`
(`PALETTE_SLUGS` + `PALETTE_LABELS`), затем прогоняешь `npm run test:visual -- --update-snapshots`.

## Типографика

- Числа и подписи — mono: `ui-monospace, "SF Mono", Menlo`.
- Заголовки — display: `"Arial Black", system-ui`, uppercase.
- Текст — sans.

Глобальные паттерны в `main.css`: `.kicker`, `.panel`, `.btn`, `.tabbar`, `.chip.streak`,
`.meter`. Компонентные стили — scoped в SFC. Прежде чем заводить новый класс, проверь,
нет ли готового в `main.css`.

## Доступность (проверяется автоматически)

- Тач-цели ≥44px, кнопки 50px.
- Контраст ≥4.5:1, включая текст на цветных плашках.
- `prefers-reduced-motion` отключает transform-анимации нажатий.
- `npm run test:a11y` гоняет axe по всем экранам в обоих режимах; serious/critical роняют сборку.
- `src/assets/styles/theme-contrast.test.ts` статически проверяет контраст всех
  text-on-surface пар по всем 28 темам. axe видит только отрендеренную тему, этот тест — все.
  Правишь палитру в `build-assets.py` — прогоняй его.

Известное расхождение: `--accent` используется как цвет текста в 13 местах, и в светлых
палитрах его контраст к `--bg` около 1.5:1. axe на текущих экранах нарушений не находит,
поэтому пара `accent/bg` намеренно не проверяется тестом. Трогаешь эти места — проверь axe.

## Проверка изменений вёрстки

```bash
npm run test:visual      # скриншот-диффы по темам и экранам
npm run test:a11y        # axe
```

Визуальный диф ожидаемый → `npm run test:visual -- --update-snapshots`, эталоны коммитятся.
Смотри диффы глазами перед обновлением: скриншот-тесты ловят именно те регрессии
(съехавшая тень, потерянная рамка, неправильный токен), которые не видит ни typecheck, ни eslint.

## Приоритет при UI-аудите

UX → логика → a11y → дизайн-язык. Мокапы — референс «ощущения», а не pixel-perfect чеклист;
расхождение с мокапом само по себе не дефект, расхождение со спекой и токенами — дефект.
