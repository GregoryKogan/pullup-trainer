# Poster / Swiss — выбранный дизайн (A8)

Выбран пользователем из семейства Dark Sport. Это **единственный** дизайн-язык продукта.
Файл мокапа: `mockups/poster-p01-volt.html` (эталонная палитра P01, 5 экранов, обе темы).

> **Роль мокапов (ТЗ §5.1.2):** HTML-мокапы передают **идею стиля** — характер, палитру, типографику, паттерны компонентов. Это **не** точные карты UI для pixel-perfect копирования. При аудите и доработке экранов приоритет — логичность, удобство и UX; мокапы — ориентир «как должно ощущаться», а не чеклист расхождений.

## Характер

Спортивный плакат в швейцарской традиции: плоские поверхности, жёсткие чёрные правила,
офсетные (смещённые) тени, гигантские цифры, капс-заголовки, неоновые «плашки»-лейблы.
Максимум типографской энергии при минимуме декора. Никаких градиентов, свечений, скруглений
(радиус 2px везде) — «печатный» характер, который хорошо переносит i18n и честно выглядит
на любых экранах.

## Принципы

1. **Плоскость.** Всё — заливки + рамка 2px. Радиус 2px. Без блюра и градиентов.
2. **Жёсткие тени.** Офсет `4–5px 4–5px 0` сплошным цветом (чёрный в тёмной теме) —
   главный источник «объёма» вместо скруглений.
3. **Типографика — главный герой.** Числа огромные и контурные, заголовки капсом,
   служебные подписи — моноширинным капсом.
4. **Плашки-лейблы.** Каждый «kicker» — цветная плашка с рамкой и тенью: заголовок раздела
   становится знаком препинания.
5. **Один акцент.** Один «кричащий» цвет + нейтрали; семантика (ok/warn/bad) — отдельная
   тройка, не пересекающаяся с акцентом.

## Типографика

| Роль | Стек | Размер / регистр |
|---|---|---|
| Заголовки экранов (`h2`) | `"Arial Black", system-ui` | 1.8rem / uppercase, -0.02em |
| Главная цифра (`focus .rep`) | `"Arial Black", system-ui` | 7.4rem / контур 2.5px акцентом |
| Крупные метрики (KPI, tile) | `"Arial Black", system-ui` | 1.7–2.4rem |
| Названия карточек/панелей (`h4`) | display | ~1rem / uppercase |
| Данные, лейблы, кнопки-утилиты | `ui-monospace, "SF Mono", Menlo` | .62–.9rem / uppercase, tracking |
| Текст (подписи, заметки) | system-ui | .7–.8rem |

Правило: **числа и подписи — моно, заголовки — display, абзацы — sans**.

## Компоненты

- **Плашка-kicker** — акцентная заливка, 2px рамка, тень 3px; стоит над каждым блоком.
- **Панель** — `card` фон, 2px рамка, тень 5px; внутри 16px отступ.
- **Кнопка** — 50px высота, капс display, тень 4px; primary = акцентная заливка,
  ghost = прозрачная. Нажатие: сдвиг на тень (translate 3px + уменьшение офсета) —
  «физическое» вдавливание; отключается в `prefers-reduced-motion`.
- **Сет-карточки** — квадраты 62px с тенью; выполненный — зелёная рамка + галочка,
  текущий — акцентная заливка.
- **Фокус-цифра** — контурная 7.4rem (только контур, без заливки; fallback на заливку
  через `@supports`).
- **Таймер отдыха** — панель с кольцом (stroke акцентом), mono-цифры, кнопки ±15s/pause/skip.
- **Календарь** — ячейки 44px display-шрифтом; сегодня = акцентная заливка, плановые —
  точка `accent2`, выполненные/пропущенные — рамки ok/bad + иконки.
- **Bottom sheet** — панель с полосой-«ручкой», варианты переноса, заметка о сдвиге.
- **Таб-бар** — сплошная акцентная полоса во всю ширину (выступает за отступы экрана),
  активная вкладка — чип цвета фона с текстом акцента.
- **Графики** — SVG: линия/столбцы акцентом, сетка рамками, подписи mono.
- **Формы** — ряды «ключ mono — значение/контрол» с нижней рамкой 2px, сегменты-кнопки,
  switch-«флажок» (квадратный).

## Правила светлой темы

Та же система, инвертированная по «бумажному» принципу:
- `--bg` — тёплая бумага (`#F4F2EA`-семейство), `--card` — белый;
- рамки и тени остаются тёмными (постерные правила не исчезают);
- акцент затемняется до тона, который держит контраст AA с тёмным текстом на плашках
  (или наоборот — белый текст на глубоком акценте, если он яркий);
- семантические цвета затемняются для контраста на белом;
- таб-бар остаётся акцентным, активный чип — цвета бумаги.

Конкретные пары тёмная/светлая сведены в палитры `mockups/poster-p*.html`
(по 5 экранов в обеих темах).

## Доступность и ограничения

- Тач-цели ≥44px (кнопки 50px, иконки 44px, ячейки календаря 44px).
- Контраст текста и текста-на-плашке ≥4.5:1 (проверено по ролям в каждой палитре).
- Фокус — 2px outline; нажатия через transform отключаются в `prefers-reduced-motion`.
- Без аудио: таймер — вибрация + уведомление (надпись на экране тренировки).
- Без эмодзи: все иконки — inline SVG.
- i18n: EN по умолчанию, капс-mono хорошо держит RU-подписи (пример-строка на экране Settings).
