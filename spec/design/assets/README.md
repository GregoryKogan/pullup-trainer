# Библиотека графических ассетов (лого, иконки, фоны)

Айдентика и UI-иконки приложения. Всё сведено к **единому дизайн-языку Poster /
Swiss** (см. `../poster-design.md`): строгая геометрия, один цвет через
`currentColor` (перекрашивается токеном `--accent` любой из 14 тем), без
градиентов и лишних деталей.

> **Лицензионная модель**: собственные знаки, иконки и паттерны созданы в рамках
> проекта — внешних ограничений нет, распространяются как часть приложения по
> GPL-3.0. Единственный внешний набор — Lucide (ISC), совместим с GPL-3.0,
> текст лицензии в `LICENSES/`.

## Логотип — `identity/custom/`

**Выбранный знак: `mark-01-v1-square-vlegs.svg`** — перекладина + фигура в висе
широким хватом, острая геометрия Poster/Swiss (квадратные срезы концов,
митер-стыки, никаких скруглений). `currentColor` — работает в любой из 14 тем.

Доработан под иконку приложения:
- перекладина сужена (10–54 вместо 6–58) — не доминирует в маленьком размере;
- руки разведены широко (плечи 18–46) — при вписывании в квадрат иконки знак
  читается крупнее;
- предплечья под углом (18,21)→(30,32) и (46,21)→(34,32) соединяют плечи
  с корпусом — заканчиваются на торсе ниже головы, а не на голове;
- голова — залитый квадрат (29–35 × 21–26), чтобы предплечья не сливались
  с её контуром при малом размере;
- толщина штриха = 5 при viewBox 64, сетка 8×8 — при масштабировании
  пропорции сохраняются.

Остальные кандидаты удалены по решению пользователя. При необходимости от знака
собираются производные: lockup (знак + словесный знак «PULL-UP»), иконка
приложения/favicon (знак в квадрате, см. `preview.html` — секция 01 показывает
знак в квадрате иконки).

## Иконки UI — `icons-ui/lucide/`

13 строгих линейных иконок для интерфейса (Lucide, **ISC**, атрибуция:
«Icons by Lucide, lucide.dev» — внести в NOTICE приложения):
`activity`, `award`, `biceps-flexed`, `calendar-days`, `flame`, `heart-pulse`,
`medal`, `repeat`, `target`, `timer`, `trending-up`, `trophy`, `zap`.

Иконки «из других видов спорта» (гантели, штанги, бег, гимнастика) удалены —
про подтягивания теперь только авторский набор выше.

## Фоновые паттерны — `backgrounds/custom/`

| Файл | Назначение |
|---|---|
| `swiss-grid.svg` | мелкая сетка «миллиметровка» — фирменный швейцарский фон |
| `halftone-dots.svg` | растровые точки по диагонали |
| `diagonal-hatch.svg` | тонкая косая штриховка |
| `pullup-bars.svg` | мотив перекладин — фоновый паттерн под тему приложения |

Паттерны ч/б с низкой непрозрачностью (0.06–0.10): накладывать через CSS
`background-image`; в тёмной теме инвертировать (`filter: invert(1)`) либо
перекрасить штрихи в токен темы.

## Следующие шаги по айдентике

1. Открыть `preview.html` — знак на светлом, тёмном фоне и в квадрате иконки.
2. Собрать lockup (знак + словесный знак «PULL-UP» фирменным шрифтом Poster).
3. Знак в квадрате → экспорт в `public/pwa-192.png`, `public/pwa-512.png`,
   `public/favicon.svg`.
4. Файлы распространять вместе с приложением (GPL-3.0) — внешней атрибуции
   для авторских файлов не требуется, кроме Lucide (строка выше).
