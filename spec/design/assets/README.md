# Графические ассеты (лого, иконки, паттерны)

Всё в едином дизайн-языке Poster / Swiss (см. `../poster-design.md`): строгая
геометрия, острые углы, один цвет, без градиентов и скруглений.

> **Лицензии**: авторские файлы (`logo/`, `icons/pullup/`, `patterns/`) созданы
> в рамках проекта — ограничений нет, распространяются по GPL-3.0 вместе с
> приложением. Единственный внешний набор — `icons/lucide/` (ISC, совместим с
> GPL-3.0), текст лицензии в `LICENSES/Lucide-ISC.txt`, атрибуция:
> «Icons by Lucide, lucide.dev» (внести в NOTICE приложения).

## Структура

```
assets/
├── README.md         ← этот каталог
├── preview.html      ← галерея: открыть в браузере, посмотреть всё сразу
├── logo/             ← логотип приложения
├── icons/            ← UI-иконки
├── patterns/         ← фоновые паттерны
└── LICENSES/         ← лицензии сторонних наборов
```

## Логотип — `logo/`

| Файл | Что это |
|---|---|
| `icon.svg` | иконка приложения 64×64: фигурка на зелёной плашке + белая жёсткая тень |
| `mark.svg` | только фигурка на прозрачном фоне (`currentColor`) |
| `icon-*.png` | рендеры иконки для PWA: 32, 48, 64, 72, 96, 128, 144, 152, 180, 192, 256, 384, 512 |

Цвета — тема по умолчанию P01 Volt (`theme-tokens.css`): фон `#C6FF3B`
(`--accent`), фигурка `#0E0E0B` (`--accent-ink`), тень `#F7F7F0` (`--ink`).

Для PWA: `icon-192.png` + `icon-512.png` — в манифест, `icon-180.png` —
apple-touch-icon, `icon-32.png` — favicon.

## Иконки — `icons/`

| Папка | Что это |
|---|---|
| `lucide/` | **12** строгих линейных иконок для галереи/референса (Lucide, ISC) |
| `pullup/` | **3** авторские иконки про подтягивания (без внешней лицензии) |

`pullup/`: `pull-up.svg` (голова над перекладиной), `dead-hang.svg` (вис),
`above-bar.svg` (стрелка над перекладиной — прогресс).

### Использование в приложении

Runtime использует **гибридную** стратегию:

- [`IconSprite.vue`](../../../src/components/icons/IconSprite.vue) — 26 inline SVG symbols (nav, controls, social).
- Lucide SFC в `src/components/icons/lucide/` — декоративные KPI (flame, target, timer и др.).
- Pullup SFC в `src/components/icons/pullup/` — контекст workout/onboarding.

Файлы в `assets/icons/lucide/` — статические копии для preview; не импортируются напрямую в runtime.

## Паттерны — `patterns/`

| Файл | Назначение |
|---|---|
| `swiss-grid.svg` | мелкая сетка «миллиметровка» — **используется в app** (`.app-shell::before`) |
| `halftone-dots.svg` | растровые точки по диагонали (резерв) |
| `diagonal-hatch.svg` | тонкая косая штриховка (резерв) |
| `pullup-bars.svg` | мотив перекладин — фоновый паттерн (резерв) |

Паттерны ч/б с низкой непрозрачностью (0.06–0.10): накладывать через CSS
`background-image`; в тёмной теме инвертировать (`filter: invert(1)`) либо
перекрасить штрихи в токен темы.
